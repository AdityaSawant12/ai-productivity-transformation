⚙️ Setup Required

A credentials.json file from Google Cloud Console is required before connecting Gmail. Follow these steps:

  1. Go to console.cloud.google.com
  2. Create a project (or select an existing one)
  3. Enable the Gmail API and Google OAuth2 API
  4. Go to Credentials → Create OAuth 2.0 Client ID
  5. Choose Web Application, set redirect URI to:
    http://localhost:5000/oauth2callback
  6. Download the JSON and save it as credentials.json in the project folder
