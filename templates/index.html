🚀 Get Started in 3 Minutes

Follow these steps to obtain your free Google OAuth2 credentials and connect MailMind.

1

Open Google Cloud Console

Visit console.cloud.google.com and create a new project called "MailMind".

2

Enable Gmail API

Go to APIs & Services → Library, search Gmail API and click Enable.

3

Configure Consent Screen

Go to OAuth consent screen, choose External, fill in your app name and support email.

4

Create OAuth Client ID

Go to Credentials → Create Credentials → OAuth 2.0 Client ID. Type: Web application.

5

Add Redirect URI

Under Authorized redirect URIs add:
http://localhost:5000/oauth2callback

6

Paste into Setup Page

Copy your Client ID and Client Secret and paste them into the MailMind setup page — done!
